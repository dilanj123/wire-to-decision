Assumptions:
- Synchronous active-high reset initializes the harness.
- Fixed-vector jobs prescribe packet metadata and byte values and advance their source index only on public ready/valid transfer.
- Safety BMC assumes upstream input byte/data/last and packet metadata remain stable when valid and not ready.
- Safety BMC leaves message_ready, out_ready, packet_result_ready, and reject_ready unconstrained; properties are masked across reset/rearm.
- No data-byte values or DUT classification/output values are assumed.

Strength/limits:
- All assertion jobs are bounded BMC, not induction/unbounded proofs.
- Error/content correspondence jobs are fixed-vector checks. The formal cases do not exhaust all 16-bit message lengths or all 16-bit message counts.
- Random/directed cocotb supplies wider behavioral coverage; Python mold.py cross-check covers representative success and error vectors.
- A first generic safety run failed because the harness demanded stall stability across a legal rearm that cancels pending state. The property was corrected to mask reset/rearm, then rerun and PASS at depth 20. No RTL counterexample was involved.
